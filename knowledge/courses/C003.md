# C003 物联网传感器实践

## 课程定位与概览

课程方向：软硬结合。难度：★★★。软件门槛：中；硬件门槛：高。建议年级：大二或大三。计划总学时：48 学时。

本课程是软硬件结合的实践课，从传感器采集、开发板编程和通信，到数据上报、可视化与简单控制，走完一条物联网应用链路。强调安全接线、调试记录和问题排查。

## 先修要求与适合人群

需要基础电路常识，了解电压、接地和串口，并具备 C 语言或 Python 基础。适合喜欢传感器、硬件制作、环境感知和软件与硬件结合的学生。

## 教学目标

- 知识：理解传感器原理、串口通信和 MQTT 协议。
- 技能：搭建采集节点、联网并上报数据，完成简单控制。
- 素养：建立先保证硬件安全再实现功能的意识，记录调试与异常处理过程。

## 建议器材与软件环境

以下为教学建议与参考型号，是否实际配齐以实验室现状为准：

| 器材 | 用途 | 参考型号 |
|---|---|---|
| 开发板 | 主控 | ESP32 DevKit、Arduino Uno 或树莓派 |
| 温湿度传感器 | 环境监测 | DHT11、DHT22、SHT30 |
| 光照传感器 | 光照采集 | BH1750 |
| 超声波模块 | 测距 | HC-SR04 |
| 气体传感器 | 烟雾或可燃气体检测实验 | MQ-2 |
| OLED 屏 | 本地显示 | SSD1306 0.96 寸 |
| 继电器模块 | 控制外设 | 5V 单路继电器 |
| 面包板、杜邦线 | 接线 | 通用型号 |
| 电源、USB 线 | 供电与连接 | 5V / 3.3V |

建议软件：Arduino IDE 2.x 或 PlatformIO；可选 MicroPython（如 ESP32 或 Raspberry Pi Pico）；Mosquitto 或 EMQX 提供 MQTT Broker；Node-RED 制作可视化看板；阿里云 IoT 或 ThingsBoard 可作为可选平台。项目中已列出的基础设备为微控制器开发板、温湿度传感器和计算机，基础软件为 Arduino IDE。

## 上课教室与选课

项目配置的上课教室：实验楼 B 座 201（物联网创新实验室）。每门课最多 20 人，每位学生最多选 2 门。教室和实时剩余名额以系统数据库中的当前信息为准。

## 综合项目与实验安全

制作实验室环境监测节点：采集温度、湿度和光照，在 OLED 本地显示，通过 MQTT 每分钟上报，超阈值时触发蜂鸣器及可选消息告警（如邮件或微信），并在看板上展示历史曲线。记录设计、接线和测试结果。

接线前断电，注意 3.3V / 5V 电平匹配，避免短路；使用明火或高压设备需教师在场。

## 考核方式与学习收获

考核：平时 20% + 实验 40% + 作品与文档 40%。完成课程后，学生能搭建基础传感采集节点，理解从采集、通信到展示和控制的流程。
