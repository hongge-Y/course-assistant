# C001 Python 数据分析实践

## 课程定位与概览

课程方向：数据处理。难度：★★。软件门槛：低；个人硬件门槛：无特殊要求。建议年级：大一或大二。计划总学时：48 学时。

面向零基础或初学者的数据分析入门课，重点是使用工具把数据转化为结论，而非算法本身。课程从 Python 与 Jupyter 基础开始，依次学习数据获取、清洗、统计与可视化，最终独立完成一份数据分析报告。

## 先修要求与适合人群

无硬性编程先修要求，有任意编程基础更好；需要掌握基本的 Excel 操作。适合对数据、图表、报表和实际问题分析感兴趣的学生。零基础学生可先练习语法，已有 Python 基础的学生可更快进入数据处理。

## 教学目标

- 知识：理解数据结构、描述统计和数据可视化的基本概念。
- 技能：使用 pandas 清洗、筛选、分组与汇总数据，使用 matplotlib 制图并撰写分析结论。
- 素养：养成先检查数据质量、再下结论的习惯，能够说明分析结果的局限。

## 课程模块与实验安排

| 模块 | 主要内容 | 学时 | 对应实验 |
|---|---|---:|---|
| 1. 环境与语法 | Python 基础、Jupyter 工作流、虚拟环境 | 6 | 环境搭建、第一个 Notebook |
| 2. 数据获取 | CSV、Excel、JSON、SQL 读取及编码问题 | 6 | 读取多源数据 |
| 3. 数据清洗 | 缺失值、重复值、异常值、类型转换 | 8 | 清洗一份脏数据 |
| 4. 统计分析 | 均值、中位数、分位数、相关性、分组聚合 | 8 | 分组统计练习 |
| 5. 数据可视化 | 折线图、柱状图、散点图、箱线图、热力图 | 8 | 复刻一张信息图 |
| 6. 探索性分析 | 提出问题、验证假设、形成结论 | 6 | EDA 小练习 |
| 7. 综合项目 | 完整分析流程与报告撰写 | 6 | 提交分析报告 |

## 软件与硬件要求

课程建议软件：Python 3.12+；Anaconda 或 Miniforge 用于包和环境管理；JupyterLab 或 VS Code 用于编写与展示；pandas、numpy 用于数据处理；matplotlib、seaborn 用于可视化；openpyxl 用于 Excel 读写；sqlite3 用于简单数据库查询。

个人硬件：普通笔记本电脑即可，i5 处理器、16 GB 内存足够，无特殊硬件要求。项目中配置的实验设备为联网计算机，每人一台；已列出的基础软件为 Python、Jupyter Notebook、pandas 和 matplotlib。其他建议软件是否已安装以实际环境为准。

## 上课教室与选课

项目配置的上课教室：教学楼 A 座 301（数据分析实验室）。每门课最多 20 人，每位学生最多选 2 门。教室和实时剩余名额以系统数据库中的当前信息为准。

## 综合项目与实践

可选择校园消费记录、公开天气数据或电商订单等真实数据集，说明数据来源与字段，记录清洗过程及处理理由，制作 3～5 张关键图表，并形成结论与建议。也可围绕图书借阅数据或课程调查数据进行分组比较，提交可运行的 Notebook 与分析报告。

## 考核方式与学习收获

考核：平时 20% + 实验 40% + 综合报告 40%。完成课程后，学生可承担数据整理、报表制作和基础分析任务，并为 C002 机器学习入门打基础。
