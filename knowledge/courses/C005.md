# C005 网络基础与安全实验

## 课程定位与概览

课程方向：网络运维。难度：★★★。软件门槛：中；硬件门槛：中，实验可使用纯模拟环境完成。建议年级：大二或大三。计划总学时：48 学时。

先学习网络如何连通，再学习如何在授权环境中发现与修补问题。课程重视实验与配置，不涉及对真实目标的攻击，重视操作记录、安全意识和授权边界。

## 先修要求与适合人群

需要计算机网络基础，也可同步学习；需要掌握基本 Linux 命令。适合对网络连接、设备配置、抓包分析和基础安全加固感兴趣的学生。

## 教学目标

- 知识：理解 TCP/IP、VLAN、路由、NAT 和防火墙。
- 技能：配置小型网络、分析抓包结果并进行安全加固。
- 素养：明确合法授权边界，具备网络安全意识，记录排查过程。

## 课程模块与实验安排

| 模块 | 主要内容 | 学时 | 对应实验 |
|---|---|---:|---|
| 1. 网络基础 | OSI、TCP/IP、IP 地址与子网划分 | 8 | 子网划分练习 |
| 2. 交换与 VLAN | 交换机配置、VLAN 隔离、Trunk | 8 | 划分部门 VLAN |
| 3. 路由与 NAT | 静态路由、RIP、OSPF、NAT | 8 | 多网段互通 |
| 4. 抓包分析 | Wireshark 过滤、TCP 三次握手 | 6 | 分析一次 HTTP 会话 |
| 5. 防火墙与 ACL | 访问控制、端口策略 | 6 | 限制越权访问 |
| 6. 安全实验 | ARP 欺骗、端口扫描、弱口令的原理与防护 | 8 | 在隔离环境复现并加固 |
| 7. 综合项目 | 企业网拓扑与加固报告 | 4 | 提交方案 |

## 软件与硬件要求

课程建议软件：Cisco Packet Tracer、eNSP 或 GNS3 用于网络拓扑模拟；Wireshark 用于抓包；VMware 或 VirtualBox 用于虚拟机；Kali Linux 可用于隔离环境中的安全实验；Windows Server 或 Linux 可用于服务和权限配置。

可选硬件包括交换机、路由器、Console 线、网线和实验机柜；也可以完全使用模拟环境。项目中已列出的基础设备为隔离交换机、路由器和计算机，软件为 Wireshark 与网络模拟工具；其他建议软件和硬件是否具备以实际环境为准。

## 上课教室与选课

项目配置的上课教室：实训楼 C 座 101（网络技术实验室）。每门课最多 20 人，每位学生最多选 2 门。教室和实时剩余名额以系统数据库中的当前信息为准。

## 综合项目与安全边界

设计一个小型企业网：划分 3 个部门 VLAN，配置路由与 NAT，设置防火墙策略，抓包验证策略并输出含风险点与整改措施的加固报告。也可完成隔离网络搭建、指定连通性故障排查和授权流量观察。

所有攻击类实验必须在隔离的虚拟机或专用实验网络中进行，不得对校园网、公网或他人设备进行扫描和测试。课程重点是理解原理与学会防护。

## 考核方式与学习收获

考核：平时 20% + 实验 40% + 项目与报告 40%。完成课程后，学生能配置基础网络、观察通信并在授权范围内进行基础加固。
